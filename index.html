❓ Tutorial do Sistema

Origem dos Dados
Carregue um arquivo CSV baixado do PJE2 X (utilizando a extensão PJE+R) ou restaure um trabalho através do botão Carregar JSON.

Filtros Dinâmicos e Colunas

  • Os filtros de Réu, Classe Judicial e Assunto só aparecem se a coluna correspondente estiver marcada.

Abas e Gestão de Fluxo

  • Processos com/sem Etiquetas: Estrutura principal de triagem.
  • Em Andamento ⏳ / Concluídos ✔: Atalhos para processos marcados.
  • Ocultar Concluídos: Remove da tela principal os processos já finalizados.

Ações na Tabela

  • ✔ Concluir: Risca o processo.
  • ⏳ Em Andamento: Destaca em laranja.
  • 📋 Copiar: Copia o número.
  • 📝 Anotações: Editor de texto formatado.
  • 📄 Detalhes: Primeiro o inteiro teor em texto/Markdown; depois a sumarização, anexo e dados estruturados.
  • MD: Ícone azul ao lado do processo para abrir e editar diretamente a sumarização em Markdown.
  • 👁️ Visualizar PDF: Ícone que aparece ao lado do processo se houver anexo – abre o PDF/imagem em nova guia.

Extração de Dados

  • Ao anexar um PDF e clicar em Extrair Dados Estruturados, o sistema lê todas as páginas, extrai o texto e tenta capturar campos como ID, Autor, Réu, Valor e Data.
  • O texto completo do PDF é armazenado no campo Texto Completo e pode ser exportado via botão Exportar Texto Completo (TXT).
  • Se o anexo for uma imagem, a extração retorna a mensagem: "ID 0000 não foi convertido por ser imagem."
  • Novo: Ao selecionar um arquivo no modal de detalhes, a extração e o salvamento são feitos automaticamente – você não precisa clicar em "Extrair" nem "Salvar".

Gerenciamento de Anexos

  • No modal de detalhes, você pode baixar o anexo (PDF/imagem) original.
  • Pode também remover o anexo para economizar espaço no JSON, mantendo o texto extraído, a sumarização e os dados estruturados.
  • Na barra principal, use o botão Baixar PDFs Selecionados para baixar múltiplos anexos de uma vez (marque os processos na tabela).
  • Use o botão Anexar PDFs por Nome para selecionar vários PDFs cujos nomes correspondem aos números dos processos — o sistema anexa automaticamente.

Copiar Processos

  • O botão 📋 Copiar Processos abre um modal com todos os números de processo atualmente filtrados.
  • Os processos são exibidos em blocos de 5 (para facilitar a visualização e cópia).
  • Cada bloco possui um botão Copiar grupo que copia apenas aqueles 5 números (um por linha).
  • Os botões gerais copiam todos os processos nos formatos: um por linha, separado por TAB ou separado por vírgula.

Salvamento, Nuvem e Exportação

  • 💾 Salvar / Carregar JSON: Pausa e retoma o trabalho.
  • 🌐 Sincronizar na Nuvem: Envia apenas processos concluídos para o Google Sheets e faz backup completo no Drive.
  • 📄 PDF / 📊 Excel: Exportam os dados filtrados.
  • 📊 Exportar Dados Estruturados: Gera JSON com os dados extraídos (ID, Autor, etc.).
  • 📄 Exportar Texto Completo (TXT): Gera um .txt com todo o texto extraído dos PDFs.
