❓ Tutorial do Sistema

Origem dos Dados:
Os dados carregados neste sistema devem ser provenientes de um arquivo CSV baixado do sistema PJE2 X, utilizando a extensão PJE+R.

Para que servem os botões?

  • 🌐 Sincronizar na Nuvem: Dispara o lote atual visível para a planilha central do Google Sheets. Se a data de chegada for idêntica, as notas e status são atualizados. Se for uma nova entrada, o histórico cria uma linha adicional, preservando o histórico de 2 a 3 anos.
  • 📄 Gerar PDF: Exporta a visualização atual (com os filtros aplicados) para um arquivo PDF. Selecione "Com anotações" para anexar os históricos detalhados ao final do documento.
  • 💾 Salvar JSON: Salva todo o seu progresso atual no computador (listagem, filtros ativos, marcações de riscado/concluir e todas as anotações textuais). Perfeito para pausar e retomar o trabalho depois.
  • 📂 Carregar JSON: Restaura um trabalho em JSON salvo anteriormente. Arquivos criados em versões antigas do sistema são higienizados e carregados automaticamente sem quebras.
  • 📊 Exportar Excel: Cria uma planilha do Excel (.xlsx) contendo todas as colunas e linhas visíveis na tela no momento, incluindo uma coluna extra contendo suas anotações.
  • 🗑️ Limpar Dados: Zera completamente o sistema, limpando a memória interna para permitir o arrasto de um novo arquivo.
  • ❓ Tutorial: Abre esta janela informativa de ajuda.

Abas e Regras de Etiquetas:

  • Processos normais ficam na aba "Processos com Etiquetas".
  • Se um processo não tiver nenhuma etiqueta mapeada no PJe, o sistema atribui a ele uma identificação temporária de "Sem Etiqueta" e isola esse lote na aba específica para não poluir o fluxo de triagem principal.

✨ Filtros Inteligentes e Dinâmicos (Visual Limpo):

  • Os blocos de Mês, Órgão, Servidor / Supervisão e Outras etiquetas são fixos e estruturais do sistema.
  • Os blocos de Polo Passivo / Réu, Classe Judicial e Assunto são inteligentes: eles só aparecem na tela se a respectiva coluna estiver marcada na barra superior de "Colunas". Se você desmarcar a coluna para economizar espaço horizontal, o bloco de filtros correspondente desaparece da tela e as restrições dele são ignoradas automaticamente, reduzindo os cliques necessários na triagem.

Ações de Controle na Tabela:

  • Caixa ✔: Risca o processo e reduz a opacidade da linha, servindo como marcação visual de "concluído/analisado".
  • Caixa ⏳: Destaca o texto do processo em laranja/vermelho, sinalizando que aquele item necessita de alguma atenção ou providência posterior.
  • Ícone 📋: Copia o número do processo instantaneamente para a área de transferência do computador.
  • Ícone 📝: Abre o editor de formatação rica para digitar notas. Processos que possuem anotações salvas ganham o indicador "[Anotado]".
