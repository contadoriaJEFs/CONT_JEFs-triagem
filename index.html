❓ Tutorial do Sistema

Origem dos Dados:
Os dados carregados neste sistema devem ser provenientes de um arquivo CSV baixado do sistema PJE2 X, utilizando a extensão PJE+R.

Para que servem os botões?

  • 📄 Gerar PDF: Exporta a visualização atual (com os filtros que você aplicou) para um arquivo PDF, pronto para impressão ou arquivamento.
  • 💾 Salvar JSON: Salva todo o seu progresso atual no seu computador. Isso inclui a listagem gerada, os filtros selecionados no momento, os processos que você "riscou" ou marcou como "a concluir", e todas as anotações (notas) feitas. Ideal para não perder o trabalho ao fechar a página.
  • 📂 Carregar JSON: Restaura um trabalho salvo anteriormente. Basta selecionar o arquivo `.json` que você baixou no botão acima.
  • 📊 Exportar Excel: Cria uma planilha do Excel (.xlsx) contendo todos os dados que estão visíveis na tela no momento, incluindo uma coluna extra com suas anotações.
  • 🗑️ Limpar Dados: Zera completamente o sistema, apagando a lista atual e os filtros para que você possa arrastar um novo arquivo CSV.
  • ❓ Tutorial: Abre esta janela de ajuda.

Na tabela de processos:

  • 1ª Caixa de Seleção (✔): Ao marcá-la, a linha do processo fica "riscada", ajudando no controle visual do que já foi triado ou analisado.
  • 2ª Caixa de Seleção (⏳ A Concluir): Ao marcá-la, a fonte de toda a linha ficará com um tom laranja/vermelho. Utilize para indicar que aquele processo requer finalização posterior.
  • Ícone 📋: Copia o número do processo rapidamente para sua área de transferência.
  • Ícone 📝: Abre uma janela grande onde você pode adicionar informações, resumos ou observações específicas sobre aquele processo. Se houver algo anotado, o ícone ficará mais escuro para chamar sua atenção.
